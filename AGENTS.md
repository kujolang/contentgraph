# ContentGraph Agent Instructions

ContentGraph models relationships among content. It is not a crawler, RAG
system, CMS, SEO advisor, or LLM semantic service. Preserve deterministic
lexical defaults, explicit evidence-method labels, stable node IDs, bounded
input discovery, and read-only source behavior.

Run `bash scripts/validate.sh` before committing. Optional embedding enrichment
must never silently replace or relabel deterministic lexical evidence.
